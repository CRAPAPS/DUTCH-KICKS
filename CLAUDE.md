# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Dutch Kicks is a live-commerce inventory platform for reselling sneakers, UFC trading cards, comics, and skateboards — primarily via Whatnot live shows. Claude API drives three automated operations: product photo verification, SKU/serial-based bid pricing, and post-sale fulfillment output (tax invoice + courier manifest) triggered by a Whatnot "Sold" webhook.

## Stack

- **Framework:** Next.js 15 (App Router), TypeScript, Tailwind CSS
- **Database:** Supabase (PostgreSQL + JSONB) — client via `@supabase/supabase-js`, server via `@supabase/ssr`
- **Icons:** `lucide-react`
- **AI layer:** `@anthropic-ai/sdk` — Claude API for listing automation

### Data Model

Single `inventory` table — category-specific fields live in a JSONB `metadata` column:

```sql
create table inventory (
  id          uuid primary key default gen_random_uuid(),
  title       text not null,
  category    text not null check (category in ('kicks','skate','fight','comics')),
  status      text not null default 'available' check (status in ('available','sold','pending')),
  price       numeric(10,2),
  image_url   text,
  ref_image_url text,           -- Online reference for Claude verification
  metadata    jsonb not null default '{}',
  created_at  timestamptz default now()
);
```

**metadata shapes by category:**
```ts
// kicks / skate
{ sku: string; size: number; colorway: string }

// fight (UFC cards)
{ serial: string; set_name: string; autograph: boolean; parallel?: string }

// comics
{ issue: number; grade?: string; key_issue: boolean; publisher: string }
```

`src/types/inventory.ts` exports a discriminated union `InventoryItem` using the `category` field as the discriminant so components get typed `metadata` without casting.

### Styling System — "Tactical Noir"

Three design tokens used throughout (defined in `tailwind.config.ts` under `theme.extend.colors`):

| Token | Hex | Usage |
|---|---|---|
| `noir` | `#0D0D0D` | Base background |
| `gold` | `#D4AF37` | UFC/Grail card borders, headings |
| `lime` | `#CCFF00` | Kicks/Skate accents, CTA buttons |

`<ProductCard />` receives `category` as a prop and applies the correct accent class. Do not hard-code color classes in individual files — extend the Tailwind config and use semantic names (`border-gold`, `text-lime`).

Frosted glass pattern used on cards and overlays:
```css
backdrop-blur-md bg-white/5 border border-white/10
```

### Component Patterns

**`<ProductCard />`** — category drives the ring/border color:
- `fight` → `ring-gold`
- `kicks` | `skate` → `ring-lime`
- `comics` → `ring-white/30`

**`<HUDHeader />`** — the pulsing LIVE NOW dot is an `animate-pulse` span that reads a `isLive` boolean from a Supabase Realtime subscription to a `show_status` table. When `isLive` is false the indicator is hidden, not just dimmed.

**`<InventoryFilter />`** — a client component. Filter state is kept in URL search params (`?category=fight`) so pages are shareable and server-rendered on first load.

### Claude API Integration

`src/lib/claude.ts` wraps the Anthropic SDK with prompt caching enabled. Three operations:

1. **Photo verification** — multimodal: sends uploaded photo + `ref_image_url`, returns `{ match: boolean, confidence: number, notes: string }`.
2. **Price suggestion** — sends SKU or serial, receives suggested starting bid + comparable sales rationale.
3. **Fulfillment pack** — triggered by Whatnot webhook; returns structured invoice + courier manifest JSON.

Always use `claude-sonnet-4-6` as the default model for these operations. Batch non-urgent price suggestions using the Anthropic Batch API.

### Whatnot Webhook

`POST /api/whatnot/webhook` — verifies the Whatnot signature header, reads `item_id` + `sale_price` from the payload, updates `inventory.status` to `sold` in Supabase, then calls the Claude fulfillment function. Returns `200` immediately and does fulfillment async to avoid Whatnot timeout.

## Key Constraints

- Two shoes in the current inventory lack reference images (Duramo SL 2 M GW8336, Treziod 2 GY0047) — their `ref_image_url` is `null`; photo verification should skip gracefully.
- Three UFC cards (Velasquez, Yan, Ortega) lack serial numbers — their `metadata.serial` is `null`; the serial field is not a DB primary key.
- The `IMAGES/` directory at the repo root contains local reference photos — do not serve these statically; they are for operator reference only.
